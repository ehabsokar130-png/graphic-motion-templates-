## Remotion Templates That Actually Look Good

Most Remotion examples out there are bare-bones "Hello World" demos. Locomotion is different. These are **45 production-quality Remotion video templates** you can copy into any React project and render right away. Each one is a self-contained React component with editable props for text, colors, and content.

No package to install. No wrapper library. Just copy the `.tsx` file and go.

Works with Remotion 4.x, React 19, and TypeScript. Every template includes spring animations, interpolation curves, and transition support out of the box.

## Remotion Template Editor — Drag and Drop Timeline

Build full videos without writing code. Locomotion Studio is a visual Remotion editor where you drag templates onto a timeline, edit props, set transitions between scenes, and copy the final composition code.

<p align="center">
  <img src="public/studio-preview.png" width="100%" alt="Locomotion Studio — Remotion template editor with drag and drop timeline, AI chat, and live preview" />

**Pick a template. Drag it onto the timeline. Edit the text. Copy the code.**

The editor bundles everything into a single Remotion composition with transitions (fade, slide, wipe, zoom) between scenes. When you're done, hit copy and paste the output into your own project.

- **Drag and drop** — browse 45 Remotion templates, click or drag to add to the timeline
- **Timeline scrubber** — visual playhead, click to seek, scene cards show duration and transitions
- **Live Remotion Player** — preview your full video in real-time as you edit
- **Remotion prompt gallery** — describe the video you want in plain English and the AI builds it. Create a video with just a prompt.
- **AI chat assistant** — type "change the title to My Product" or "add a pricing scene" and it updates the canvas
- **Remotion themes** — switch between 6 style variants (Default, Brutalist, Rounded, Minimal, Glass, Neo)
- **Code export** — copy the bundled Remotion composition code, ready to render with `npx remotion render`

## Why Use a Remotion Editor?

Remotion is powerful but starting from scratch means writing a lot of boilerplate: sequences, transitions, timing math, spring configs. Locomotion's editor handles the composition layer so you focus on content. Pick templates, arrange them, tweak the text, and export a clean bundle of Remotion code.

The AI chat only touches canvas content (scene props, template selection, transitions). It won't generate arbitrary code or answer off-topic questions, so it stays focused on your video.

## How to Use These Remotion Templates

```bash
# 1. Clone or copy a template component into your Remotion project
cp templates/fade-slide-up/Composition.tsx src/

# 2. Register it in your Root.tsx
import { FadeSlideUp } from './Composition'

# 3. Render it
npx remotion render src/index.ts FadeSlideUp out/video.mp4
```

Each template is a single `.tsx` file. No dependencies beyond Remotion and React. Edit the props to change text, colors, and timing.
